Metodo A · Transcripcion con la Web Speech API

Grabacion en tiempo real desde el navegador. Se compara despues con Gemini usando py -3 src\comparar.py.

1. Configuracion

El nombre debe coincidir con el del fichero en audios/. Sirve para saber donde guardar el resultado.

2. Opcion A - Grabar con el microfono

Habla al microfono. La transcripcion aparece en vivo, frase a frase.

Parado.
3. Opcion B - Reproducir un audio y transcribirlo

Para puntuar la Web Speech API sobre los mismos ficheros que usas con Gemini. Reproduce el audio por los altavoces mientras el microfono captura: el sonido vuelve a entrar por la microfono, asi que la senal llega degradada. Usa auriculares solo si quieres transcribir otra voz (el micro no oiria el audio, entonces dara silencio).

Parado.
4. Texto transcrito
Guarda el texto en resultados/<nombre>.webspeech.txt

Que hace falta

  • Chrome o Edge. Firefox y Safari no implementan webkitSpeechRecognition.
  • Conexion a internet: Chrome envia el audio a servidores de Google.
  • Permiso de microfono en el navegador.
  • En Chrome el dictado se corta solo a los ~60 s. Usa el boton de parar para dejar la frase completa y anadirla a mano si hace falta.
